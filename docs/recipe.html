The five stages

Each runs on the output of the last, at full precision, before any quantization. Every stage that claims exactness has to prove it against a matched perturbation control — absolute thresholds are unusable here, since a 1e-7 perturbation moves logits by 5e-3.

A

Norm fusion → ScaleNorm

Fold each RMSNorm's gain into the weights of every consumer projection: W @ (γ ⊙ x̂) = (W @ diag γ) @ x̂, leaving a parameter-free norm — which is ScaleNorm with a fixed gain.

gate bit-exact vs the unmodified model

Trap

Qwen3.5's RMSNorm is zero-centered: out = x/rms(x) · (1 + weight), weight initialized to zeros. Fold (1 + weight) and reset to 0.0, not 1.0. Folding weight directly destroys the model — measured max logit delta 25.1, top-1 agreement 3.9%.

Three norms are deliberately not fused: the final model.norm (tied to lm_head), q_norm/k_norm (gain applied after normalization, so a nonlinearity sits between projection and gain), and linear_attn.norm (opposite ±1 convention — the gated norm stores the gain, ordinary norms store gain−1).

B

GatedDeltaNet → KDA (transKDA)

Lift the 18 linear-attention layers to Kimi Delta Attention by tiling the per-head scalar decay into a diagonal: A_log (H,) → (H, Dk). This is the canonical embedding of GDN inside KDA, so the richer parameterization starts as a no-op.

gate bit-exact at the tiled init

Optional decay seeding spreads channels across retention horizons. It is not exact, and a 13-arm ablation found the channel assignment is high-variance and unpredictable — control σ = 1.26 on ppl@32768, with the best single arm a random permutation. Weight-derived assignment beat random by 0.3σ, which is not evidence.

C

NoPE

Drive every rotary frequency to identity — cos → 1, sin → 0. No weight change, fully reversible, so a sweep costs only forward passes. Qwen3.5 uses partial rotary (64 of 256 head dims), so this touches a quarter of each head.

cost +12.70% ppl@2048 at surgery

A matched control that kept RoPE and trained on identical data closed roughly a third of the recovery on its own, so NoPE-specific recovery is about two-thirds of the raw before-and-after.

D

TransMLA with CARE whitening

Replace K and V on the 6 full-attention layers with one shared low-rank latent, balanced before factorization so the rank budget isn't spent on whichever matrix is larger. The SVD runs in the whitened basis — M = W·L where C = LLᵀ — which optimizes activation error rather than weight error.

ratio d_c = 256 → 4.00× KV

Whitening is worth up to 26.76 pp of perplexity against plain SVD at this rank. q_proj is never touched: Qwen3.5 sets attn_output_gate, so half its output is the output gate and naive head-merging corrupts it.

R

Recovery

Distillation from the unmodified Qwen3.5-0.8B, teacher run live each step, with exact full-vocabulary KL computed in chunks so neither model's (T, 248320) logits are ever resident.

# calibrate the whitening covariances, then recover

Adaptation surface

Corrections since this was written

The parameter counts below are wrong, and the conclusion they support is no longer established. Three findings landed after this section was drafted; docs/findings.md §2.0–2.0d carries the measurements.

1. Every run had two LoRA adapters per target. train_recovery injects LoRA twice when --init-adapters is set, and inject_lora matched rule patterns by substring — so the second pass wrapped the .base of every already-wrapped module. The result was base(x) + lora_inner(x) + lora_outer(x): effectively rank 32 at 2× the adapter parameters. Every LoRA figure in the table is therefore double the intended one, and the 293.91 M total is inflated.

2. The LoRA arms were handicapped by the learning rate. A single parameter group put the adapters on the dense-safe 3e-5, roughly 5–10× below normal LoRA practice. Re-running the LoRA-heavy arm with adapters at 2e-4 recovered 41% of its gap to the dense surface — so "dense is worth it" was partly a statement about an untuned learning rate.

3. in_proj_a is low-rank. Its update needs rank ~22–26 where every other KDA operator needs 180–300, because Stage B builds it by repeat_interleave and it starts at exactly rank 16. Its rank is still climbing at step 150, so it should stay dense rather than be constrained — but the arm that made it dense while giving the high-rank operators rank-16 adapters had the allocation exactly inverted.

LoRA configuration

Plain LoRA, no DoRA or VeRA variant: out = base(x) + scale · (x @ Aᵀ) @ Bᵀ. A is (rank, in) with Kaiming-uniform init (a = √5); B is (out, rank) initialized to zeros, so the adapted model starts exactly at the base model. Adapters are bf16; the wrapped base is frozen on injection.

Scale is 1.0. scale = (alpha or rank) / rank and alpha is left unset, so alpha = rank and the ratio is unity at every rank — there is no rank-dependent LR scaling, and no per-parameter-group learning rates anywhere in the optimizer.

Under --train-attn the linear_attn. and self_attn. prefixes unfreeze the dense base weights alongside their adapters, so those modules carry both paths and no adapter merge is needed to switch a module from low-rank to dense.

Optimizer and schedule

8-bit AdamW (bitsandbytes), lr 3e-5, betas (0.9, 0.95), weight decay 0 — on zero-centered norms, decay pulls the gain toward 1 and would erase exactly what Stage A folded. One-cycle schedule, max_lr = lr, pct_start 0.05. A single parameter group: dense and low-rank parameters share one learning rate.

Learning rate is not transferable between surfaces

2e-4 is a LoRA-scale rate and destroys a dense run: at 294 M dense parameters it drove the model to 163% worse than control before annealing back to 104%. 3e-5 is the dense-safe value used throughout.

What the objective is — and is not

Recovery uses output-level full-vocabulary KL against a live teacher. It does not use attention distillation. A layer-local hidden-state transfer exists in the codebase (LoLCATs-style, train_transfer.py) and is not invoked by any recovery run; matching attention maps is O(n²) and infeasible at the lengths where the damage lives — 16 GiB per layer at 32k.

The teacher-free cross-entropy term is available (--lm-weight) and is set to 0. It exists to cover positions where a truncated top-k target is silent, which full-vocabulary KL does not have.

Why the teacher runs live

An offline cache of the teacher's top-64 logits is ~35% cheaper per step and was the original design. It is wrong in two ways that took a day to find, both of which distort exactly the long-range behaviour the conversion damages.

Truncation — the gradient points the wrong way

At k = 64 over a 248,320-token vocabulary, top-k distillation closes roughly 5% of the gap between plain cross-entropy and full distillation, with a parameter gradient about 48° off the full-distillation direction at 1.8× the norm. On this corpus the true next token falls outside the cached top-64 on 10.8% of positions, where the loss says nothing at all.

Context — the objective penalizes correct retrieval

A cache built on independent 2048-token blocks conditions each stored distribution on at most 2047 tokens, while training draws windows up to 32768. Forward KL is mode-covering, so a teacher that cannot see the first copy of a needle spreads its mass and the loss penalizes a student that retrieves correctly. Measured at a 4096-token gap: teacher NLL on the needle 2.01 → 16.50, top-1 accuracy 87.5% → 0%, and a retrieving student scored +2.90 nats worse than one mimicking the uninformed teacher.

Running the teacher live removes both, costs roughly 30–50% wall-clock, and gives every layer's hidden states for free should a layer-local term ever be wanted.

Infrastructure that is load-bearing

  • fp32 norm gains. At w ≈ 0.5 the bf16 ULP is 3.91e-3 while an Adam step at 2e-4 is ~2e-4 — the update rounds to exactly zero. All 55,552 gains are cast to fp32; q_norm/k_norm receive no gradient at all otherwise.
  • Checkpoint on requires_grad, never a name list. A hardcoded filter silently discarded in_proj_a's 37.7 M dense parameters — the run trained them, the eval curve showed the benefit, the weights were dropped on save.
  • Length-conditional gradient checkpointing. Worth 1.43×: at 8192 the un-checkpointed peak is 25.5 GiB, which fits; at 32768 it does not, and checkpointing is mandatory there.
  • causal_conv1d built for sm_87 (TORCH_CUDA_ARCH_LIST=8.7, source build — no published wheel targets this board). 12× on that op, correct to 5.5e-3 relative, and it runs 18 times per forward.
  • No torch.compile. Inductor decomposes SDPA instead of preserving FlashAttention, materializing a 16 GiB n² attention matrix at 32k. It regresses 13% at short context and OOMs at long.
  • Resumable runs. Weights, Adam moments, one-cycle position and both sampler RNG streams, written once per eval at ~1.1 GiB. Restarting from a weight checkpoint alone re-initializes the moments and restarts the schedule at zero — a different run, not a continuation.

Still unsettled

  • Rank allocation. CARE's water-filling over a fixed budget is implemented and corrected — the original priority function handed 67% of the budget to the layer that compressed best. The whitened version reduces summed activation error by 5.02% at identical 4.00× KV, and made starting perplexity 0.8% worse. Optimizing its own proxy is not evidence; it stays off.
  • Attention logit scaling (SSMax). The premise holds here — mean attention entropy climbs +0.98 from 512 to 4096 tokens, and per-head scaling cuts that climb by 54%. 48 parameters, a bit-exact no-op at the reference length in bf16. Implemented, never trained.
  • Vision. The ViT is intact and untouched at the original checkpoint — 153 tensors, its own 48×48 absolute position grid, and internal 2D rotary, none of which language-trunk surgery can reach. It is dropped at load rather than damaged. Reattachment is unwritten.
  • Convergence. No run in this project has reached it. Every one ended on wall-clock with the loss still descending.

Mercurius is the Roman god of translation and of boundaries — of carrying something across into a new form, and of doing it quickly. These models are Qwen3.5 carried across into a cheaper architecture, not built from nothing. Sizes are parameter counts; the family name is the only mythological one.
